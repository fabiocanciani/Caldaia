# Caldaia ON OFF
App Android sperimentale per Sonoff THS PSA-BHA-GL firmware 3.6.3, IP 192.168.10.154.
La porta 8081 è raggiungibile ma non è confermato il supporto LAN del firmware.
I pulsanti inviano richieste POST /zeroconf/switch: potrebbero non funzionare.
Non usare per sistemi critici o senza verificare fisicamente lo stato del relè.
